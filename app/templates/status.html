📥 Fill Vinted

  1. On an item in the app: click “Fill on Vinted” → Vinted opens.
  2. Click the Fill Vinted bookmark — title, description, price and photos fill in.
  3. Check the category/brand/size and hit Upload yourself.

⚡ One-click auto-fill (optional)

Want to skip the bookmark click, so “Fill on Vinted” fills the form all by itself? It needs a small extension (browsers only allow auto-fill on Vinted via an extension):

  1. Install the Tampermonkey extension.
  2. In Chrome: chrome://extensions → enable Developer mode (or Tampermonkey → Details → Allow User Scripts).
  3. Open the auto-fill script and click Install.
