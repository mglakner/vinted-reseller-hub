# Vinted Hub

A self-hosted app that automates the boring parts of reselling on
[Vinted](https://www.vinted.com): a phone-friendly item tracker, AI product
photos, assisted one-click listing, automatic sale logging, and a live
profit/ROI dashboard — all running on your own hardware (a Raspberry Pi is
plenty).

Add an item on your phone → get a clean studio product photo → list it on
Vinted in one click → sales log themselves → your accounts are an export button.

> **Unofficial project.** Not affiliated with, endorsed by, or connected to
> Vinted or Higgsfield. Please read the [disclaimer](#-disclaimer) before use.

---

## Features

- **📸 Add items from your phone** — snap a photo, enter brand + price, done. Installs as a PWA ("Add to Home Screen").
- **🎨 AI product photos** — turn a raw photo into professional studio shots (flat-lay, hanger, ghost-mannequin, macro, …) via [Higgsfield](https://higgsfield.ai). You pick which shots per item to control credit spend, and each can be watermarked with your handle.
- **🚀 Assisted Vinted listing** — a button pre-fills Vinted's own new-listing page (title, description, price, photos) via a bookmarklet or a one-click userscript. **You always press Upload yourself** — the app never publishes for you, so your account stays clean.
- **📱 Phone listing helper** — save the generated photos to your camera roll and copy the text, then paste into the official Vinted app.
- **📬 Automatic sale logging** — a Gmail watcher reads Vinted "item sold" emails and marks items sold with price and date.
- **📈 Live dashboard & insights** — profit, ROI, sell-through, days-to-sale, profit-per-brand/category, and price-drop suggestions for slow movers.
- **📊 Accounts export** — one-click Excel export for taxes/backup.
- **📧 Weekly email report** — Monday-morning summary of the week's sales and profit.

## How it works

- **FastAPI + SQLite**, server-rendered HTML. No build step, no JS framework. Runs happily on a Raspberry Pi.
- Background jobs (APScheduler) handle sale-email parsing, gentle Vinted stat sync, image generation, and the weekly report.
- Product photos are generated by calling the **Higgsfield hosted MCP** directly — no browser automation.
- Everything is behind a single app password; the Vinted listing step is deliberately human-in-the-loop.

## Quick start (Docker)

```sh
git clone https://github.com/MadsRudolph/vinted-reseller-hub.git
cd vinted-reseller-hub
cp .env.example .env
#  - set APP_PASSWORD and SECRET_KEY (python -c "import secrets; print(secrets.token_hex(32))")
#  - set VINTED_DOMAIN to your marketplace (e.g. www.vinted.co.uk) and CURRENCY
docker compose up -d --build
```

Open `http://localhost:8000`, log in with your `APP_PASSWORD`, and add an item.
For a full self-hosting guide (public HTTPS URL, backups, connecting Higgsfield/
Gmail/Vinted), see **[DEPLOY.md](DEPLOY.md)**.

## Run locally (without Docker)

```sh
python -m venv .venv && . .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Without `APP_PASSWORD` set, login is disabled (development only).

## Connecting the integrations

All three are optional — the app is useful with none of them, and each degrades gracefully.

| Integration | What it adds | Setup |
|---|---|---|
| **Higgsfield** | AI product photos | `python -m app.higgsfield_mcp login` (one-time OAuth), then `HIGGSFIELD_BACKEND=mcp`. Needs Higgsfield credits. |
| **Vinted** | views/likes/status sync + listing pre-fill data | Paste your browser session cookie + user ID on the app's **Status** page. |
| **Gmail** | auto sale logging + weekly report | A Gmail app password in `.env` (must be the inbox that receives your Vinted sale emails). |

Assisted listing (the "Fill on Vinted" button) needs a one-time bookmarklet or
userscript — instructions are on the app's **Status** page.

## Configuration

Everything is set via environment variables (`.env`) — see
[`.env.example`](.env.example): `APP_PASSWORD`, `SECRET_KEY`, `VINTED_DOMAIN`,
`CURRENCY`, `HIGGSFIELD_BACKEND`, `WATERMARK_TEXT`, `GMAIL_ADDRESS`,
`GMAIL_APP_PASSWORD`.
